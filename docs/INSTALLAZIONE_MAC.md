# Installazione su Mac

## Prova locale

1. Estrai lo ZIP.
2. Clic destro su `Avvia-su-Mac.command`.
3. Scegli `Apri`.
4. Usa `http://127.0.0.1:4173`.
5. Chiudi con `Control+C` nel Terminale.

## Installazione definitiva

1. Pubblica l'app su HTTPS tramite Vercel o GitHub Pages.
2. Apri l'URL con Safari.
3. Scegli `File > Aggiungi al Dock`.
4. Apri l'app dal Dock.
5. Configura Supabase dentro l'app installata.
6. Accedi e sincronizza.

`Aggiungi al Dock` richiede macOS Sonoma 14 o successivo.
